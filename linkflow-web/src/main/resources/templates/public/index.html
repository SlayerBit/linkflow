How redirects work

Short links resolve through the API gateway at /r/{shortCode} (e.g. http://localhost:8080/r/abc123). The gateway forwards the request to the backend, which returns an HTTP 302 redirect to the original URL. This web UI does not intercept redirects — it only manages your links via the REST API.
