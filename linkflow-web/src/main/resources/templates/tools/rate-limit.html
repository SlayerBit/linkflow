About rate limiting

LinkFlow applies a Redis sliding-window limiter (sorted set, 60-second window) to API requests. Authenticated users are limited to 100 requests/minute; anonymous IPs to 200 requests/minute. Responses include X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset headers. Exceeding the limit returns HTTP 429.

Requests are fired server-side using your authenticated session token, so they consume your user rate-limit quota (not the browser IP).
